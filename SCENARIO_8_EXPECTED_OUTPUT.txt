3. DOCTOR PROFILE / AVAILABILITY

4. LOGIN
   Email: patient@example.com (or Patient ID P1001)
   Password: 123456
   Valid login returns a bearer token.

5. BOOK APPOINTMENT
   Choose doctor, date and time slot.
   Enter patient name, email and 10-digit Indian mobile number.
   POST /api/appointments returns appointment ID and status "Booked".

6. APPOINTMENT HISTORY
   GET /api/appointments (protected)
   Reschedule: PATCH /api/appointments/:id
   Cancel: DELETE /api/appointments/:id

7. TOKEN / LOGOUT
   Axios attaches Authorization: Bearer token.
   Invalid token returns 401 and clears local token.
   Logout calls POST /api/logout and clears session token.

8. STATE MANAGEMENT
   Redux Toolkit async actions update data/loading/error states.
   Middleware logs appointment actions in browser developer console.
   Doctor API results are cached in localStorage by query.
